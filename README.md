# 완분 적재대 관리 (1단계 목업)

완분창고 → 오버브릿지 → 롤러컨베이어로 나온 완분박스를 AMR이 **중간 자동적재대**에 넣고,
**어느 칸에 어떤 재종·로트가 있는지** 기록·표시하는 PC 프로그램. AMR은 지금은 앱 안의 가상 AMR이고,
나중에 실제 AMR을 사면 `src/amr/` 드라이버만 바꿔 붙인다 → [docs/AMR_연동_가이드.md](docs/AMR_연동_가이드.md).

SAP·POP 연동 없음. 데이터는 `app\data\rack.db` 한 파일(SQLite).

## 실행

- **`완분적재대 실행` 바로가기** 더블클릭 (= `app\완분적재대.exe`). 설치 필요 없음.
- 같은 폴더로 두 번 켜면 두 번째는 "이미 실행 중" 안내 후 닫힌다.
- 폴더째 다른 PC로 복사해도 된다 (`app\data` 에 재고가 같이 간다).

## 화면

| 영역 | 내용 |
|---|---|
| 상단 | 적재 n/80 · 컨베이어 n/5 · AMR 상태 · 배속(1×/5×/20×) · [오버브릿지 출고 시작] · [자동 배차] · 시뮬레이션 시각 |
| 왼쪽 적재대 | 북면·남면 정면도 (열 1 = 도크 쪽, 1단 = 맨 아래). 칸 색 = 재종(ISO 색 계열), 로트 끝자리·입고 경과·잔량 표시. 점선 = AMR이 넣으러 오는 칸, 빨간 테두리 = 확인 필요, 빗금 = 사용중지 |
| 검색 | 재종·박스·로트·칸 검색 → 해당 칸만 밝게 + **출고 순서(선입선출) 번호** |
| 칸 정보 | 칸을 누르면 박스 정보·최근 이력·[수동 출고] [이동] [내용 수정] [비우기] [사용중지] |
| 입고 탭 | 스캔 입력(바코드/RFID 리더 그대로 사용, 한글 입력기 자동 끔), 수동 등록, 샘플 박스, 컨베이어 목록, [수동 적재] [도착 취소] |
| 출고 조회 | 재종별 선입선출 목록, [적재대에서 보기], [수동 출고] |
| AMR·작업 | 셀 지도(AMR 위치·적재 박스), AMR 상태·배터리·트레이, 작업 목록, [일시정지] [재개] [작업 취소] [비상정지] |
| 이력 | 모든 입고·적재·출고·수정 기록, 필터, CSV 저장 |
| 기준정보 | 재종 표(추가·수정·색·사용중지), 적재대 열·단(비어 있을 때만), 배정 정책, 가상 AMR 대수·사다리 단수·충전 기준 |

### 스캔 형식
`PC9030` · `PC9030 0001015661578` · `PC9030,0001015661578,14.2` · `BOX:W261020-0007;PC9030;0001015661578;15`
로트는 현장 형식(숫자 일련번호)이다. 재종 뒤 숫자가 6자리 이상이면 로트, 짧으면 중량으로 읽는다. 로트를 비우면 프로그램이 이어지는 번호를 붙인다(샘플·시뮬레이션용).
박스 ID는 일회성 — 빈박스로 회수되면 라벨을 떼므로 같은 ID는 다시 등록하지 않는다.
같은 스캔이 2초 안에 다시 들어오면 무시한다(중복 읽힘 방지). 잘못 들어간 박스는 [도착 취소].

### 적재 칸 배정 정책
`같은 재종 열 우선`(기본) · `아래 단 우선` · `면 균형`. 사다리 3단 AMR이 한 번에 박스 3개까지 실어 나른다.

### AMR 작업이 중간에 멈추면
아직 안 집은 박스는 예약만 풀리고 컨베이어에 남는다. 이미 AMR에 실린 박스는 칸이 **빨간 테두리(확인 필요)** 가 된다 —
실물을 보고 [적재 완료 처리] 또는 [컨베이어로 되돌림].

## 재종 샘플
P(강) NC3010·NC3020·NC3030·NC3215·NC3225·PC3700 / M(스테인리스) NC9020·PC9030·NC5330·PC5300 /
K(주철) NC6205·NC6215·PC8110 / N(비철) H01·H05 / S(내열) PC5400·PC9530 / H(고경도) PC6510.
ISO 범위는 샘플 — 기준정보 탭에서 사내 재종표로 고친다.

## 개발자용

```bash
python src/main.py                         # 개발 실행 (데이터: ./data)
python -m pytest -q                        # 전체 시험 (재고·AMR·연결·화면)
python src/main.py --selftest build/selftest.log   # 화면 없이 2시간 시뮬레이션 + 불변식 검사
python build.py                            # app\완분적재대.exe 다시 만들기 (app\data 는 유지)
```

```
src/
  main.py            진입점 (--selftest, --shot, 단일 실행 잠금)
  controller.py      재고 ↔ AMR 연결, 자동 배차, 시뮬레이션 시계, 자가 시험
  core/              재고: models, config, grades(샘플 재종), rack(칸 ID·배정 정책), inventory(SQLite 트랜잭션·불변식), conveyor(오버브릿지 시뮬)
  amr/               AMR 제어 베이스: models, driver(추상), sim_driver(가상), vda5050, tcp_json(템플릿), fleet(배차·구역 잠금·충전·주차), topology(셀 지도)
  ui/                PyQt5 화면
tests/               pytest
docs/                AMR 연동 가이드
SPEC.md              사양·결정 사항
```

## 아직 안 한 것 (다음 단계)
- AMR 출고 배송(적재대 → 설비), 설비 호출
- 2대 이상 실기 운전용 통로 교통 제어, AMR 응답 없음 감시
- 실제 박스 ID 체계(바코드/RFID 라벨이 박스에 고정인지 채울 때마다 새 번호인지) 결정
